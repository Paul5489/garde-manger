# Garde-manger sur l'iPhone — mode d'emploi

Adresse de l'application : **https://paul5489.github.io/garde-manger/**

Tes recettes ne sont jamais sur Internet : elles sont copiées une fois dans ton iPhone, depuis ton iCloud Drive.

---

## 1. Installer l'application (une seule fois)

1. Sur l'iPhone, ouvre **Safari** (pas Chrome).
2. Tape l'adresse **paul5489.github.io/garde-manger** et ouvre-la.
3. Touche le bouton **Partager** (le carré avec une flèche vers le haut, en bas de l'écran).
4. Fais défiler et touche **« Sur l'écran d'accueil »**.
5. Vérifie que **« Ouvrir comme app web »** est activé, puis touche **Ajouter**.
6. L'icône **Garde-manger** (un bocal sur fond orange) apparaît sur ton écran d'accueil.

À partir de maintenant, **ouvre toujours Garde-manger depuis cette icône**, jamais depuis Safari :
l'application installée et Safari ne partagent pas leurs données.

## 2. Importer les recettes (une seule fois)

Le fichier est déjà prêt dans ton iCloud Drive, dossier **Garde-manger**.

1. Ouvre **Garde-manger** depuis l'icône.
2. Touche **Importer mes recettes**.
3. Dans la fenêtre qui s'ouvre, touche **Parcourir** (en bas), puis **iCloud Drive** › **Garde-manger** › **archive_complete.json**.
4. Patiente quelques secondes : c'est prêt (821 fiches).

> Si le fichier apparaît avec un petit nuage, touche-le une fois et attends qu'il se télécharge.

## 3. Hors ligne

Une fois installée et les recettes importées, l'application fonctionne **sans Internet** (mode avion compris).

## 4. Minuteurs et écran

- En **mode cuisine**, l'écran reste allumé tout seul.
- Les minuteurs sonnent **même écran verrouillé et en mode silencieux** : ils apparaissent sur l'écran
  verrouillé comme une musique (« ⏱ Potage — sonne à 14:05 »). Ta musique est mise en pause pendant ce temps.
  Tu peux couper cette option dans la liste des minuteurs (touche la pastille orange).
- Si tu mets le minuteur en pause depuis l'écran verrouillé, tous les minuteurs se mettent en pause.

## 5. Mettre à jour les recettes

Quand l'archive a été régénérée sur le Mac :

1. Sur le Mac, dans le Finder : copie `Documents/Cuisine/archive-recettes/donnees/archive_complete.json`
   dans **iCloud Drive › Garde-manger** (remplace l'ancien).
2. Sur l'iPhone : Garde-manger › ⚙️ Réglages › **Mettre à jour les recettes**, choisis le fichier.

Tes favoris, notes, courses et bocaux sont conservés.

## 6. Mettre à jour l'application

Quand une nouvelle version est publiée, un bandeau **« Nouvelle version disponible »** apparaît en haut :
touche **Mettre à jour**. (Il faut être connecté à Internet à ce moment-là.)
